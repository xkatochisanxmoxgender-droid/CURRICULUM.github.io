Proyecto personal de análisis de datos · Python, Pandas, SQL, GitHub

▾ Ver resumen

Diseñé de principio a fin un proyecto de análisis con datos públicos reales de The Coca-Cola Company (informes a la SEC). Yo definí la idea y las preguntas; usé Claude Code como herramienta para generar el código y yo lo revisé, corregí errores y validé los resultados.

• Armé una proyección simple y documenté los límites de los datos con honestidad.
• Subí el proyecto a GitHub con README en inglés.
